# Tahap 2C.1 — Visual & Theme Upgrade

## Yang dikerjakan
1. **Hero video** (`components/store/hero-video.tsx`, `app/(public)/page.tsx`): `hero-bg.mp4` jadi latar section hero saja (absolute, object-cover, overlay gelap, z-index terkunci via `isolate`). Poster `hero-poster.jpg` dirender server (LCP + fallback). Video dipasang di klien: autoplay, muted, loop, playsInline, tanpa kontrol; TIDAK dimuat saat `prefers-reduced-motion`, Save-Data, atau koneksi 2G; dijeda saat hero keluar layar. Judul diperkecil di HP kecil (`2rem` -> `text-4xl` mulai 380px) + `break-words` supaya tidak terpotong.
2. **Dark/Light Mode**: `html[data-theme]`, default dark. Skala warna zinc/emerald/red/amber Tailwind DIBALIK lewat CSS variables di `globals.css`, jadi semua halaman customer + admin ikut berganti tanpa mengubah className. Dark Mode tidak berubah. Hero memakai `.theme-dark-scope` sehingga video + teks putih tidak berubah saat tema diganti. Pilihan disimpan di `localStorage` (`malik-theme`); skrip kecil di `<head>` menerapkannya sebelum paint (tanpa flash), `suppressHydrationWarning` pada `<html>`.
3. **Tombol tema + animasi karakter** (`components/theme/theme-toggle.tsx`): tema berubah langsung saat klik; animasi 1,9 dtk hanya dekorasi (SVG + CSS keyframes, transform/opacity saja, `pointer-events:none`, tanpa overlay, tanpa geser layout). Klik berulang: tema tetap berganti, animasi yang sedang jalan tidak diulang. Timer dibersihkan saat unmount; jaring pengaman bila `animationend` tidak terpicu. Dilewati total saat reduced-motion. Lokasi tombol: header (publik + dashboard user), bar admin (HP) / sidebar admin (desktop), pojok kanan atas halaman login.
